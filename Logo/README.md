# Логотип Team Tracker

Знак — круг со стрелкой (цикл, спринт) и галочка (готово). Две цветовые гаммы, в каждой версии для светлого и тёмного фона. Решения — [ADR-013](../docs/adr/013-logo-and-palettes.md).

- `blue/` — «Стандартная» гамма (синяя);
- `beige/` — «Бежевая» гамма (по умолчанию в приложении).

## Какой файл где использовать

| Файл (в каждой папке гаммы) | Что это | Где использовать |
|---|---|---|
| `mark.svg` | знак без надписи, 64×64, цвета для светлого фона | аватар, водяной знак, всё, где надпись не нужна |
| `logo-light.svg` | знак + «Team Tracker» для **светлого** фона | шапки, документы, презентации на белом и светлом |
| `logo-dark.svg` | знак + «Team Tracker» для **тёмного** фона | то же на тёмном фоне |
| `app-icon.svg` | знак на плашке 64×64, скругление `rx=16` | значок приложения, закладка на рабочий стол, карточки |
| `favicon.svg` | то же, линии толще для 16–32 px | вкладка браузера |
| `app-icon-512.png`, `app-icon-192.png` | PNG значка приложения | манифест PWA, магазины, соцсети |
| `favicon-32.png` | PNG favicon 32 px | старые браузеры, закладки |

Логотипы с надписью прозрачные (без фона): подкладывайте под них фон нужной яркости. Не растягивайте и не перекрашивайте: используйте готовые файлы.

В приложении знак нарисован встроенным SVG, цвета берутся из CSS-переменных активной гаммы (`--logo-ring`, `--logo-check`), надпись — HTML-текстом. Значок вкладки браузера (`public/favicon*.svg`) копируется из этих файлов.

## Цвета

| Гамма | Элемент | Светлый фон | Тёмный фон |
|---|---|---|---|
| blue | круг со стрелкой и «Team» | `#2B4ACB` | `#7B93FF` |
| blue | галочка и «Tracker» | `#F08C00` | `#F08C00` |
| blue | плашка значка | `#EEF2FF` | — |
| beige | круг со стрелкой и «Team» | `#484039` | `#EEEEE5` |
| beige | галочка и «Tracker» | `#95816C` | `#C5BFAF` |
| beige | плашка значка | `#EEEEE5` | — |

Надпись: шрифт `'Source Sans 3', 'Myriad Pro', 'Segoe UI', Arial, sans-serif`, жирность 700. Шрифт в SVG не встроен: если он не установлен, браузер подставит следующий из списка (ширина надписи чуть изменится; запас в `viewBox` рассчитан на Segoe UI и Arial).

Геометрия (viewBox `0 0 64 64`): кольцо `M52.78 20 A24 24 0 1 1 35.34 8.23`, толщина 6, закруглённые концы; наконечник — полигон `45.24,9.62 36.31,1.30 34.37,15.16`, обводка 2; галочка `23,33 29.5,39.5 41,27`, толщина 6. Для 16–32 px толщина линий 7–8 (в `favicon.svg` ≈ 7 после масштабирования).

Контраст: логотип (логотип-надпись) под WCAG 1.4.3 не нормируется, но знак читается на фонах своей гаммы (≥ 3:1 для круга).

## Как пересобрать

```bash
python3 scripts/build_logo.py     # SVG в Logo/ и значки в public/
node scripts/build_logo_png.cjs   # PNG 512, 192 и 32 px (Chromium из Playwright)
```
