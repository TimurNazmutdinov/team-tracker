# Видение

team-tracker — трекер задач и спринтов для команд разработки. Задача продукта: дать быстрый, предсказуемый инструмент для планирования и отслеживания работы без лишней церемонии.

## Функции MVP

- **Проекты** с ключом задач (например, `DEMO-12`).
- **Типы задач:** Epic, Story, Task, Bug, Sub-task.
- **Связи:** blocks, relates, duplicates.
- **Статусы:** Backlog → To Do → In Progress → Review → Done.
- **Бэклог** с ручным порядком и приоритетом (Highest / High / Medium / Low).
- **Спринты:** цель, дата старта, закрытие, перенос незавершённого в следующий спринт или бэклог.
- **Story points** у задач.
- **Итоги по людям и спринтам** — вычисляются, не хранятся.
- **Доска** с группировкой по выбранному полю (исполнитель, тип, приоритет, эпик и т. д.).
- **Burndown и velocity.**
- **Комментарии** к задачам.
