## 2. Перенос трекера на новый компьютер

**На старом компьютере**

1. «Настройки → Резервные копии → Сделать копию сейчас» — свежая проверенная копия на всякий случай.
2. Остановите трекер: закройте его окно. Пока трекер работает, папку базы копировать нельзя:
   копия получится испорченной.
3. Перенесите на новый компьютер (флешка, облако) всё нужное из раздела 1. Файл
   `local-data.lock` не берите: это метка работающего трекера, на новом компьютере она может
   помешать запуску.

**На новом компьютере**

1. Установите Node.js 22 (https://nodejs.org) и Git (https://git-scm.com).
2. Создайте папку `C:\Projects` и скачайте в неё проект:

   `cd C:\Projects && git clone https://github.com/TimurNazmutdinov/team-tracker.git`

3. Положите в `C:\Projects\team-tracker` перенесённые `local-data`, `.env` и `backups`.
4. Запустите трекер (первый раз — несколько минут):

   `cd C:\Projects\team-tracker && npm ci && npm run build && npm run start`

   Дальше — как обычно: двойной щелчок по `start.cmd` или та же команда без `npm ci`.
5. Войдите прежней учётной записью: база та же.
6. Откройте «Настройки → Резервные копии → Папка для копий». Если там путь со старого компьютера,
   выберите папку заново.
7. Если коллеги заходили по сети, повторите на новом компьютере раздел README «Как открыть доступ
   коллегам по локальной сети».

**Если база не открылась** или вы перенесли только резервную копию, восстановите данные из неё.
Трекер должен быть остановлен; программа покажет, что будет восстановлено, и спросит `y`:

`cd C:\Projects\team-tracker && npm run restore backups\<папка копии>`

После переноса работайте только на новом компьютере: две базы разойдутся, слить их нельзя.

## 3. Продолжение работы в новом Claude Code

- Claude Code сам читает [CLAUDE.md](../CLAUDE.md) из корня репозитория: там ваши правила, команды,
  карта кода и подводные камни.
- **Claude Code на компьютере** (приложение Claude или `claude` в терминале): откройте папку
  `C:\Projects\team-tracker`. Для pull request нужен вход в GitHub: Git попросит его при первом
  `git push`, а для команд `gh` один раз выполните `gh auth login`.
- **Claude Code в облаке** (claude.ai/code): выберите репозиторий `TimurNazmutdinov/team-tracker`.
  Если это другой аккаунт Claude, подключите в нём GitHub и дайте приложению Claude доступ к
  репозиторию.
- Первое сообщение новому Claude Code:

  > Прочитай CLAUDE.md, docs/handover.md и docs/rework.md (разделы 6–7). Продолжаем переработку
  > с части G2 — программы (домены). Сначала покажи эскиз; код — после моего согласования.

## 5. Откат на версию до переработки

1. Остановите трекер.
2. Код: `cd C:\Projects\team-tracker && git checkout -b before-rework cae352a`
3. Данные: переименуйте `local-data`, создайте пустую папку `local-data` и распакуйте в неё архив:
   `tar -xzf local-data-before-update-<дата>.tar.gz -C local-data`
4. Запустите: `npm run build && npm run start`.

Вернуться на текущую версию: `git checkout main`. При запуске база снова обновится автоматически.
