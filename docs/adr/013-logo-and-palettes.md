# ADR-013. Логотип и цветовые гаммы

- **Статус:** принято
- **Дата:** 2026-10-29

## Контекст

У продукта появился логотип (круг со стрелкой — цикл спринта, галочка — «готово») в двух цветовых вариантах. Приложение должно выглядеть в этих цветах, а пользователь — выбирать гамму. Прежняя тема ([ADR-004](004-screen-decisions.md), п. 4) была одна (синяя, светлая или тёмная по системе), цвета были разбросаны по стилям. Требования: две гаммы, у каждой светлая и тёмная версии; цвета в одном месте; контраст текста и кнопок не ниже WCAG AA.

## Решение

**1. Логотип** — в `Logo/blue/` и `Logo/beige/`: `mark.svg`, `logo-light.svg`, `logo-dark.svg`, `app-icon.svg` (плашка 64×64, `rx=16`), `favicon.svg`, PNG 512/192/32 px; описание и коды цветов — `Logo/README.md`. Файлы генерирует `scripts/build_logo.py` из одной геометрии знака (`viewBox 0 0 64 64`; для 16–32 px линии толще: в favicon ≈ 7), PNG — `scripts/build_logo_png.cjs` (Chromium из Playwright). «Team» — цветом круга, «Tracker» — цветом галочки; шрифт `'Source Sans 3', 'Myriad Pro', 'Segoe UI', Arial, sans-serif`, 700 (в SVG не встроен — подставляется следующий из списка). Цвета: blue — `#2B4ACB` / `#F08C00` (светлый фон), `#7B93FF` / `#F08C00` (тёмный); beige — `#484039` / `#95816C` (светлый), `#EEEEE5` / `#C5BFAF` (тёмный), плашка `#EEEEE5`; плашка blue — `#EEF2FF`.

**2. В приложении** знак — встроенный SVG (`src/ui/Logo.tsx`) с цветами из переменных `--logo-ring` и `--logo-check` активной гаммы, надпись — HTML-текстом. Показывается в шапке и на экранах входа, смены пароля и ошибки запуска. Значок вкладки — `public/favicon-<гамма>.svg`; при смене гаммы подменяется без перезагрузки (`public/favicon.svg` — бежевый, для первой загрузки).

**3. Гаммы и токены.** Две гаммы — «Бежевая» (по умолчанию) и «Стандартная» (прежняя синяя); у каждой светлая и тёмная версии выбираются по системе (`prefers-color-scheme`). **Все цвета заданы только в `src/ui/tokens.css`** как CSS-переменные; `styles.css` не содержит ни одного hex или `rgb()` (проверяет тест). Гамма выбирается атрибутом `data-palette` на `<html>`; без него действует бежевая. Бежевая: фон `#ECECE2`, поверхности `#F7F6F0`, текст `#484039`, дополнительные `#C5BFAF`, `#B7A286`, `#ABAFA3`, тёмная — тёмно-коричневые фоны (`#2A241F`, `#362F28`) и текст `#EEEEE5`.

**4. Контраст (WCAG AA).** Тест `src/ui/tokens.test.ts` разбирает `tokens.css` и для всех четырёх вариантов проверяет: текст, второстепенный текст, ссылки, текст кнопок, ошибки, предупреждения и подписи статусов — **не ниже 4.5:1**; границы полей ввода и кнопок (`--control-line`) и круг логотипа — **не ниже 3:1**. Где палитра не дотягивает, оттенок затемнён: брендовый `#95816C` даёт 3.1:1, поэтому цвет текста и кнопок (`--accent`) в бежевой гамме — `#6E5A47` (5.5:1 к фону, 6.5:1 для белого текста на кнопке), а `#95816C` остаётся только в логотипе (`--logo-check`). Тонкие разделители (`--line`) — декоративные, границы управляющих элементов используют `--control-line`. Логотип (знак и надпись) по WCAG 1.4.3 и 1.4.11 исключён из требований контраста: оранжевая галочка `#F08C00` на белом — 2.5:1 — задана макетом логотипа.

**5. Выбор гаммы — в профиле пользователя**, в меню профиля (блок «Цветовая гамма», любая роль). Применяется сразу, без перезагрузки. С сервером выбор хранится в учётке (`users.palette`, миграция, `PATCH /api/auth/preferences`) и поэтому виден при входе с любого компьютера; доступен и с временным паролем. В демо-режиме — в `localStorage` браузера. Последняя выбранная гамма всегда дублируется в `localStorage`: экран входа и первая отрисовка сразу идут в ней без «мигания», а после входа гамма берётся из профиля. Значение по умолчанию и список гамм — `src/domain/palettes.ts`, общий для сервера и клиента.

**6. Резервные копии** ([ADR-012](012-backups.md)) сохраняют гамму: поле `palette` в `tracker.json` и колонка «Цветовая гамма» на листе «Люди» в Excel; в копиях без этого поля при восстановлении берётся бежевая.

## Рассмотренные варианты

- **Гамма на всю команду (настройка проекта).** Проще, но у людей разные привычки и зрение; выбор в профиле соответствует просьбе и не требует ролей.
- **Хранить выбор только в браузере.** Не виден с другого компьютера; серверное хранение нужно по условию.
- **Токены в TypeScript и генерация CSS.** Лишний шаг сборки; CSS-файл — один источник, тест читает его напрямую.
- **Светлую/тёмную версии гаммы выбирать вручную.** Остаётся по системе, как в [ADR-004](004-screen-decisions.md); ручной переключатель — позже.
- **Использовать `#95816C` как цвет текста и кнопок.** Не проходит AA (3.1:1); затемнён до `#6E5A47`.

## Последствия

- Любой новый цвет добавляется в `tokens.css` во все четыре варианта; тест не даст расхождения набора переменных и просадки контраста.
- Снимки экранов в `wireframes.md` нарисованы в синей гамме («Стандартная»); приложение по умолчанию бежевое.
- Шрифт логотипа не встроен: надпись в SVG-файлах зависит от шрифтов системы; в приложении используется тот же список шрифтов.
- Старый значок вкладки заменён на значок логотипа.
